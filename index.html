    Changelog

    v1.1.4 — Waypoint naming + settings cleanup

    • Waypoint names are now entered from a compact field directly beneath the diamond placement tool.
    • Removed the old marker-name textbox from the Map Tools sidebar.
    • Removed the Calibration Debug toggle and Calibration settings section.

    v1.1.3 — Floating toolbar click fix

    • Fixed the floating toolbar being stuck on Pan / inspect.
    • Toolbar pointer events no longer get captured by the underlying map pane.

    v1.1.2 — Floating map tools

    • Moved Pan / inspect, Add marker, and Distance + bearing ruler out of the Map Tools panel.
    • Added a compact floating icon toolbar on the map using hand, diamond, and ruler icons.
    • The active interaction tool remains highlighted and each icon has an accessible tooltip/label.

    v1.1.1 — Map display toggles

    • Added a dedicated landmark visibility toggle in Settings → Map display.
    • Towers and landmarks can now be hidden or shown independently.

    v1.1.0 — Hosted website support

    • Prepared the app for static hosting on GitHub Pages.
    • Added hosted-site loopback/local-network handling for the live-position plugin.
    • Added update detection: if a newer deployed version exists, the site can prompt you to reload it.
    • Added version.json and .nojekyll for straightforward static deployment.

    v1.0.2 — Live game location

    • Added direct connection to the BigWalkLivePosition localhost bridge.
    • A LIVE YOU marker now follows the player's in-game position automatically.
    • The live marker can be used as the active reference for marker-based questions.
    • Live status, Big Walk Y/X, and altitude are shown in Map Tools.

    v1.0.1 — First-launch map fix

    • Fixed a local-file startup race where the map image could finish loading before the app attached its load handler.
    • The app now initializes correctly whether the map image is already cached or loads normally.

    v1.0 — Landmarks + multi-marker support

    • Added two landmarks: Purple Tunnel and Microphone.
    • Added landmark questions: nearest landmark and landmark radius.
    • Added a separate landmark unlock timing (default 40 minutes).
    • Markers now support multiple saved positions at once.
    • You can set an active marker, remove one marker, or clear them all.
    • Marker-based questions now use the active marker.

    v0.9 — Question pacing

    • Added a global question cooldown, defaulting to 5 minutes.
    • After any successful answer, all unlocked questions lock until the cooldown expires.
    • Undoing the most recent question immediately reverses that cooldown.
    • Cooldown duration is configurable in Settings.
    • Added this Changelog tab for future versions.
    • Kept the default unlock schedule at 10 / 20 / 30 / 50 minutes.

    v0.8 — Direction experiment

    • Briefly tested straight half-map cardinal cuts for marker-direction questions.
    • Superseded in v0.9; the intended broad compass-sector behavior is retained.

    v0.7 — Coordinate entry + question cleanup

    • Added manual Y,X marker placement.
    • Reduced marker-direction choices to N / E / S / W.
    • Moved question history, Undo, and Clear to the Questions tab.
    • Tightened gridline questions to X15–19 and Y36–40.

    v0.6 — UI redesign

    • Moved to a full-screen map with top navigation tabs and floating panels.
    • Added customizable question unlock timings.
    • Removed duplicate top-left map HUD readouts.

    v0.5 — Match system

    • Added the match timer and staged question unlocks.
    • Added the Rules tab and marker-based late-game questions.
    • Added grid/radius validation and the 250-unit minimum radius.

    v0.4 — Navigation tools

    • Added the YOU marker, nearest-tower helper, distance/bearing ruler, and copy tools.

    v0.3 — Map inspection

    • Added live coordinates beside the cursor and improved calibration debugging.

    v0.2 — Calibration

    • Added the five-tower affine calibration that aligns game coordinates to the map.
