    Rules

    Hiders

    • No hiding behind the giant wall.
    • No hiding inside the tunnel system.
    • No hiding on the chairlift or train.
    • Stay in your hiding spot except during an active forced relocation or future mission.
    • During forced relocation, remain inside the current legal search area and move the required displacement from your relocation start point.
    • All hiding spots must be accessible by foot.

    Changelog

    v1.3.0 preview — Impossible Route reroll fix

    • Impossible Route now generates a compact connected replacement patch instead of requiring a second sector roughly 90 degrees away.
    • The replacement still cannot be closer than the original target and prefers legal cells outside the rejected purple zone.
    • If the original target already covers nearly the whole far side, the reroll can use a smaller shifted far-side patch rather than producing no target.

    v1.3.0 preview — Impossible Route fallback

    • Cross the Zone now offers one guarded Impossible Route reroll during the first 90 seconds and only within 20 units of the mission start.
    • The replacement target must be at least as far away and substantially different from the rejected target.
    • After the reroll, Abort mission is the only fallback and requires returning within 5 units of the original hiding spot for no reward.
    • Purple target raster cells no longer count or draw over eliminated coordinates.

    v1.3.0 preview — Cross the Zone target polish

    • The purple mission overlay now uses the same raster alignment as eliminated zones.
    • Cross the Zone now includes the true far edge and highlights a broad far-side band, giving the Hider more route choices around difficult terrain.

    v1.3.0 preview — Cross the Zone completion

    • Cross the Zone no longer auto-completes when the Hider first enters the purple target.
    • While inside the target, the Hider can settle on a new hiding spot and press Complete mission to finish.

    v1.3.0 preview — Match control polish

    • Moved host match controls into compact Play / Pause / Reset icons beside the match timer.
    • Reset appears only while a started match is paused.
    • Added a visual and audio cue when hiding time ends.

    v1.3.0 preview — Mission reset + cues

    • Match reset now explicitly clears available/active mission state and all local mission progress.
    • Added Hider-only visual/audio cues when a mission becomes available and when it is accepted.
    • Resetting an active mission no longer plays a misleading mission-cancelled cue.

    v1.3.0 preview — Mission + role UI pass

    • Restored an always-visible Hider-only mission status card and added configurable mission timing.
    • Added in-room role switching while preserving the one-Hider rule.
    • Changed the Hider match subtitle to Hiding, Relocate, or Mission Active instead of question status.
    • Shortened Centerline display labels to Y 37 / X 17 and refreshed the tower visibility icon.

    v1.3.0 preview — Private relocation ranges + map controls

    • Forced relocation now uses configurable first/repeat ranges with the exact trigger privately rolled by the Hider client.
    • Seeker hosts can configure relocation without receiving the selected future trigger time.
    • Completing or cancelling Cross the Zone rerolls a fresh private relocation delay.
    • Moved Fit, Grid, Towers, and Landmarks into a second floating map-control dock.
    • Removed the old Tower data and Landmark data Settings groups.

    v1.3.0 preview — Gameplay clarity pass

    • Made question cards collapsible and moved role economy into the center of the top bar.
    • Added animated visual notifications that identify gameplay sounds as they occur.
    • Relocation scheduling and normal relocation activity are now private to the Hider; Seekers only see intentional reveal effects.
    • Question unlock/cooldown cues are Seeker-only and relocation cues are Hider-only.
    • Fixed Settings number fields being overwritten while a user is editing an unapplied draft.

    v1.3.0 preview — Room + question cleanup

    • Moved room creation/joining onto the default Game page and hides it after joining.
    • Added top-bar Leave Room and a player-count popover; Hiders no longer see the Questions tab.
    • Made question cards denser with larger question names.
    • Added configurable hiding time, optional first-question unlock at hide-time end, and a contextual hiding countdown.
    • Added configurable point prices for every current question type and radius tier.
    • Development / testing is pinned to the bottom of Settings.

    v1.3.0 preview — UI organization pass

    • Reduced the primary navigation to Game, Questions, Map, and More.
    • Added role-aware current-objective dashboards and reduced competing countdowns.
    • Upcoming events now use compact approximate timing; active forced relocation is the only large contextual countdown.
    • Locked question cards collapse automatically, question history is collapsible, and Settings categories are expandable.
    • Connected live-location details collapse to a compact status card.

    v1.3.0 preview — Hider missions

    • Added Cross the Zone as the first Hider mission.
    • Cross the Zone privately highlights a purple far-side target inside the connected legal search area.
    • Starting the mission cancels the pending forced-relocation countdown; completing or cancelling it starts a fresh relocation interval.
    • Mission completion awards one Power Charge for the upcoming Hider power system.
    • Missions are optional and completely private to the Hider UI: Seekers receive no mission countdown, availability, active-state, progress, or completion indication.
    • Mission targets remain local to the Hider browser and are never uploaded to the room.

    v1.2.0 — Multiplayer rooms + live gameplay

    • Added shared multiplayer rooms with one Hider and multiple Seekers.
    • Added synchronized match state, question history, seeker points, and question cooldowns.
    • Added forced relocation with private Hider tracking, adaptive movement targets, and Ready confirmation.
    • Added distinct Web Audio feedback for unlocks, cooldown completion, relocations, and match controls.
    • Rebalanced the old Gridline question into fixed centerlines at Y 3700 and X 1700.

    v1.1.4 — Waypoint naming + settings cleanup

    • Waypoint names are now entered from a compact field directly beneath the diamond placement tool.
    • Removed the old marker-name textbox from the Map Tools sidebar.
    • Removed the Calibration Debug toggle and Calibration settings section.

    v1.1.3 — Floating toolbar click fix

    • Fixed the floating toolbar being stuck on Pan / inspect.
    • Toolbar pointer events no longer get captured by the underlying map pane.

    v1.1.2 — Floating map tools

    • Moved Pan / inspect, Add marker, and Distance + bearing ruler out of the Map Tools panel.
    • Added a compact floating icon toolbar on the map using hand, diamond, and ruler icons.
    • The active interaction tool remains highlighted and each icon has an accessible tooltip/label.

    v1.1.1 — Map display toggles

    • Added a dedicated landmark visibility toggle in Settings → Map display.
    • Towers and landmarks can now be hidden or shown independently.

    v1.1.0 — Hosted website support

    • Prepared the app for static hosting on GitHub Pages.
    • Added hosted-site loopback/local-network handling for the live-position plugin.
    • Added update detection: if a newer deployed version exists, the site can prompt you to reload it.
    • Added version.json and .nojekyll for straightforward static deployment.

    v1.0.2 — Live game location

    • Added direct connection to the BigWalkLivePosition localhost bridge.
    • A LIVE YOU marker now follows the player's in-game position automatically.
    • The live marker can be used as the active reference for marker-based questions.
    • Live status, Big Walk Y/X, and altitude are shown in Map Tools.

    v1.0.1 — First-launch map fix

    • Fixed a local-file startup race where the map image could finish loading before the app attached its load handler.
    • The app now initializes correctly whether the map image is already cached or loads normally.

    v1.0 — Landmarks + multi-marker support

    • Added two landmarks: Purple Tunnel and Microphone.
    • Added landmark questions: nearest landmark and landmark radius.
    • Added a separate landmark unlock timing (default 40 minutes).
    • Markers now support multiple saved positions at once.
    • You can set an active marker, remove one marker, or clear them all.
    • Marker-based questions now use the active marker.

    v0.9 — Question pacing

    • Added a global question cooldown, defaulting to 5 minutes.
    • After any successful answer, all unlocked questions lock until the cooldown expires.
    • Undoing the most recent question immediately reverses that cooldown.
    • Cooldown duration is configurable in Settings.
    • Added this Changelog tab for future versions.
    • Kept the default unlock schedule at 10 / 20 / 30 / 50 minutes.

    v0.8 — Direction experiment

    • Briefly tested straight half-map cardinal cuts for marker-direction questions.
    • Superseded in v0.9; the intended broad compass-sector behavior is retained.

    v0.7 — Coordinate entry + question cleanup

    • Added manual Y,X marker placement.
    • Reduced marker-direction choices to N / E / S / W.
    • Moved question history, Undo, and Clear to the Questions tab.
    • Tightened gridline questions to X15–19 and Y36–40.

    v0.6 — UI redesign

    • Moved to a full-screen map with top navigation tabs and floating panels.
    • Added customizable question unlock timings.
    • Removed duplicate top-left map HUD readouts.

    v0.5 — Match system

    • Added the match timer and staged question unlocks.
    • Added the Rules tab and marker-based late-game questions.
    • Added grid/radius validation and the 250-unit minimum radius.

    v0.4 — Navigation tools

    • Added the YOU marker, nearest-tower helper, distance/bearing ruler, and copy tools.

    v0.3 — Map inspection

    • Added live coordinates beside the cursor and improved calibration debugging.

    v0.2 — Calibration

    • Added the five-tower affine calibration that aligns game coordinates to the map.
